## 2026-08-26 — Six independent pages

The supplied document is treated as six separate service pages, not one landing page.

## 2026-08-26 — European Repair is a hub

The European Car Repair page is structurally different from the other five because it contains seven brand chapters and many issue/service groups. It will use the same design system but not the same short-page composition.

## 2026-08-26 — Documentation before code

The project begins with content architecture, design DNA, skill/plugin setup, and QA rules. No visual baseline is implied by the starter structure.

## 2026-08-26 — Design phase is platform-free

No production-platform system or handoff constraints are used during the design phase. Adaptation happens later, after the visual system and pages are approved.

## 2026-08-26 — Existing-site internal pages

The six deliverables are new internal SEO/service pages inside the current Acton Autowerks website. They are not a standalone campaign or microsite. Preserve the current global shell and identity.

## 2026-08-26 — Extend, then systematize

Do not build a new abstract design system first. Audit the current site, design one representative service page, approve it, then extract and document the reusable service-page extension system before producing the remaining pages.
