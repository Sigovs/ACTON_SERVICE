# QA checklist

## Required viewports

- 1920×1080
- 1440×900
- 1024×1366
- 390×844

## Content

- Correct page title and service identity
- All supplied headings and body copy accounted for
- Phone number matches 978-429-8913
- CTA language matches approved source/decision
- No invented claims, certifications, prices, or affiliations
- Auto Body onsite/partner distinction remains explicit
- European page includes all seven brands and every supplied issue/service group

## Visual

- One dominant idea per view
- No accidental repeated-template rhythm across all six pages
- Real hierarchy at thumbnail scale
- Readable body copy and line length
- Intentional image crop at each viewport
- No decorative card inflation, gradient buttons, or gratuitous glow
- Header, content, CTA, and footer resolve as one composition

## Responsive and accessibility

- No horizontal overflow
- No clipped headings, buttons, controls, or media
- 44 px minimum touch targets where applicable
- Logical heading order
- Keyboard navigation and visible focus
- Hover/focus parity
- FAQ/disclosure state communicated programmatically
- Meaningful alt text; decorative images ignored correctly
- Contrast checked for text, controls, and focus indicators
- Reduced motion produces a complete page
- No important imagery or information simply hidden on mobile

## Technical

- Implementation matches the confirmed production/handoff profile
- No unnecessary dependencies or framework substitutions
- No hotlinked fonts or unapproved external assets
- Shared tokens and components are used consistently
- Console has zero errors and zero warnings


## Evidence

- Desktop full-page screenshot
- Mobile full-page screenshot
- Focus/keyboard spot check
- Reduced-motion spot check
- Forward and reverse interaction recording when scroll/motion behavior exists
- Files-changed report and unresolved-issues report
