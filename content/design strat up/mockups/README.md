# Mockup structure

Create one folder per page only after a direction and shared shell are approved:

- `01-tires-wheels/`
- `02-maintenance/`
- `03-european-repair/`
- `04-electrical-systems/`
- `05-auto-body/`
- `06-transmission/`

Shared production assets belong in `_shared/`:

- `_shared/assets/images/`
- `_shared/assets/fonts/`
- `_shared/assets/video/`
- `_shared/assets/icons/`
- `_shared/styles/`
- `_shared/scripts/`

The exact deliverable format is intentionally undecided until the production/handoff profile is confirmed. Do not create six duplicate copies of shared assets or choose a framework by assumption.
